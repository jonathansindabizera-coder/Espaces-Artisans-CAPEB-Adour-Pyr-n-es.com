# AGENTS.md

## Cursor Cloud specific instructions

### What this is
"Espace Artisan CAPEB" — a single-page management app for French building-trade
artisans (devis/PV, planning, RH, formations, marchés, avantages). Stack:
TanStack Start (React 19 SSR) + Vite 7 + Tailwind v4, built via
`@lovable.dev/vite-tanstack-config`. Supabase provides auth + a few server
functions, but **most feature data lives in the browser `localStorage`**
(see `src/lib/local-data.ts`), so the core app is fully usable without any
backend secrets.

### Running (commands live in `package.json`)
- Dev server: `npm run dev` → http://localhost:8080 (port/host are fixed by the
  Lovable config; not 5173).
- Build: `npm run build` (Nitro/Vercel preset; emits `.vercel/output`).
- Preview built output: `npm run preview`.
- Lint: `npm run lint`; auto-fix formatting: `npm run format`.

### Non-obvious caveats
- Package manager: the repo ships both `bun.lock` and `package-lock.json`. We use
  **npm** here (bun is not installed). `.npmrc` sets `legacy-peer-deps=true`, so
  plain `npm install` is required (peer-dep conflicts otherwise).
- `npm run lint` currently reports a large number of pre-existing
  `prettier/prettier` formatting errors on committed source. This is the repo's
  existing state — ESLint itself works; don't mass-reformat files unless asked.
- No Supabase env vars are needed to run/browse the app. Without
  `VITE_SUPABASE_URL` / `VITE_SUPABASE_PUBLISHABLE_KEY` the client logs a warning
  and runs in "offline mode"; the `_authenticated` routes do **not** gate on
  login — they redirect to `/bienvenue` (onboarding) until a company profile
  exists in `localStorage`. Server-only Supabase admin code
  (`client.server.ts`, `api/sync-formations.ts`) throws if `SUPABASE_URL` /
  `SUPABASE_SERVICE_ROLE_KEY` are missing, but those paths aren't hit during
  normal local browsing.
- First load redirects `/` → `/tableau-de-bord` → `/bienvenue` (two-step
  onboarding). Fill at least the company name to proceed; data persists in
  `localStorage`.
- `src/routeTree.gen.ts` is auto-generated by the TanStack router plugin — don't
  edit by hand. Routes are file-based under `src/routes/` (see
  `src/routes/README.md`).
